The 4-Step Upgrade Path

Each step builds on the last. Start with free value, earn trust, expand.

Free Fixes

Fix how their AI handles different caller types. Add text follow-ups. Immediate value, zero cost.

Solo Upgrades

Pro or Elite Plan

Unlock call volume, calendar booking, and outbound follow-up for the individual user.

Branch Upgrade

Cover the branch line + individual rep lines. Transfer, shared inbox. 24/7 instant service.

Every individual, branch & national line. System integration for real answers. Full AI coverage.

Principles

How this playbook works

Event-Triggered

Outreach fires when the system detects a revenue-stakes call that could've been handled better. Not scheduled drips.

Privacy-Safe

Reference call timestamp only. Never mention caller name, phone number, or conversation topic.

Free First

Always lead with a free improvement. Earn trust before suggesting paid upgrades. Each step builds on the last.

Max 1x/Week

One alert per week per user. Aggregate multiple events into a weekly digest. User can opt out. Pause after 3 no-responses.
